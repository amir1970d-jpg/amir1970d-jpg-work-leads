# work-leads
1. ریپوی جدید در GitHub بساز (مثلاً work-leads) و همه‌ی این فایل‌ها را آپلود کن (پوشه‌ی .github هم).
2. در Netlify همین ریپو را وصل کن (بدون build command، publish directory = ریشه).
3. در GitHub: Actions > leads > Run workflow. بعد از اجرا، leads.json بروز می‌شود و Netlify خودش دوباره منتشر می‌کند.
4. در sources.json اسم کانال‌های تلگرام را بگذار و "disabled" را حذف کن.
